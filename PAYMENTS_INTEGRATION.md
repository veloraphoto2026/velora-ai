# Velora AI — подключение платной модели (черновик)
Текущий сервер использует Replicate; интеграция Ranvik ещё НЕ реализована. Не запускать платные генерации до успешных тестов.

## Что уже подготовлено
- Отдельная ветка и черновик PR, без изменений production.
- Новым пользователям предусмотрен нулевой стартовый баланс.
- Генерация закрыта до реализации проверенной оплаты.
- SQL-миграция для заказов и дедупликации уведомлений. **Миграция не применялась**.

## Безопасный порядок подключения
1. Уточнить юридический статус продавца и выбрать провайдера оплаты, который реально поддерживает его.
2. Получить официальную документацию API Ranvik, список моделей, цены, форматы входа/выхода и правила хранения изображений.
3. Настроить секреты только в переменных окружения Render; не хранить их в GitHub и браузере.
4. Реализовать создание заказа сервером с фиксированной ценой из конфигурации (не принимать цену от клиента).
5. Проверять подлинность уведомлений об оплате по официальной спецификации провайдера, сверять сумму, валюту, заказ и статус с серверной проверкой.
6. Обрабатывать повторные webhook-события идемпотентно в транзакции; начислять только подтверждённые покупки.
7. Реализовать резервирование оплаченного баланса при генерации и безопасный возврат при ошибке; предусмотреть параллельные запросы.
8. Протестировать регистрацию, оплату, повторы webhook, ошибку генерации, возвраты и лимиты. Только затем объединять PR и публиковать.

## Важные ограничения
- Не менять существующие credits у зарегистрированных пользователей без отдельного решения о миграции.
- Не хранить пользовательские фото в открытом доступе без явной политики хранения.
- Пока нет проверенного платежного провайдера и документации Ranvik, не объявлять сервис готовым к платным заказам.
