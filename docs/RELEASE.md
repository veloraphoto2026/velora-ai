## Параметры целевого приложения, которые нужно проверить до запуска

- Build: `npm ci --omit=dev`, start: `npm start`, Node.js 24, NODE_ENV=production, health: `/api/health`.
- Правильная рабочая DATABASE_URL и постоянный случайный JWT_SECRET минимум 32 байта. Значения не заменять без согласования: ротация JWT завершит старые сессии.
- ENABLE_GENERATION=false для первоначального запуска. Наличие токена само по себе больше не включает расходы на генератор. Включать только после отдельного согласия на интеграцию/платный контрольный запрос.
- TRUST_PROXY_HOPS=0 для прямого подключения. На Render установить 1 только после подтверждения единственного доверенного последнего прокси, дописывающего адрес клиента. При неверной конфигурации все пользователи могут разделить один лимит либо IP-лимит станет обходиться. Не доверять всем forwarded-адресам.
- При нескольких экземплярах нужен общий store лимитов: текущий MemoryStore ограничивает один процесс и сбрасывается при рестарте.
- Проверка TLS не отключена в коде. Проверить совместимость целевой строки подключения/цепочки доверия, не устанавливая rejectUnauthorized=false.

При запуске выполняются CREATE TABLE IF NOT EXISTS и ALTER DEFAULT credits=2. Они не удаляют строки и не сбрасывают существующие балансы, но изменяют схему/значение по умолчанию. Это требует подтверждённой копии перед рабочим развёртыванием. Ограничение CHECK создаётся только для новой таблицы; существующая таблица автоматически не перестраивается.
