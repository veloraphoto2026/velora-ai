# Velora AI — запуск: проверка готовности

Дата: 2026-11-06. Эта ветка не развёрнута в production.

## Подтверждено по исходному коду
- API фото: POST /api/orders/:id/generate-photo; требует оплаченный заказ и RANVIK_API_KEY.
- Административный тест: GET/POST /api/admin/ranvik-test; требует VELORA_ADMIN_EMAIL и VELORA_RANVIK_TEST_ENABLED=true; POST потенциально платный, без отдельного подтверждения не вызывать.
- Редактирование и видео: /api/edit и /api/video возвращают HTTP 402, пока не реализованы.
- /api/services сообщает paymentsEnabled=false и generationEnabled=false.
- Robokassa live не включать до подтверждения активации и фискализации.

## Обязательные проверки перед выпуском
1. Проверить наличие переменных окружения без раскрытия их значений. Render-интеграция не предоставляет чтение переменных; отсутствие доступа не означает отсутствие ключа.
2. Проверить актуальную документацию Ranvik: модель, схему запроса и ответа, отдельные методы редактирования и видео, цены и асинхронные задачи.
3. Добавить интеграционные тесты с заглушкой Ranvik (без списаний), тесты авторизации, прав на заказы, повторных запросов, ошибок и таймаутов.
4. Предусмотреть устойчивое хранение результата генерации и безопасную выдачу результата клиенту: сейчас в orders нет ссылки на результат.
5. Не менять действующие заказы, регистрацию и платёжную логику; провести миграции только с сохранением данных.
6. Сначала проверить на отдельной ветке/стенде; production — после проверки.

## Статус
Подготовка. Реальные платежи отключены. Платные вызовы Ranvik не запускались в рамках этой работы.
